# 北京高中班级新媒体工作台

纯前端静态页面，放在仓库根目录，供 GitHub Pages 从 `main` 发布。打开 https://zby228.github.io/bj-class-media/ 即可使用。选题、成稿、封面和草稿都在浏览器里完成，不需要登录或后端。

## 模块

- **创作台（新对话）**：选平台、功能、年级和选题，本地生成草稿，可复制全文
- **选题工坊**：按年级和平台生成本周选题，点一条即可填进创作台
- **热点雷达**：北京高中班级节点的本地示例（军训、家长会、选科、一模二模、运动会、期末等），不是平台实时热榜
- **知识库**：草稿和提示词片段，保存在本机 localStorage
- **做配图**：用 canvas 画 1080×1440 封面，下载 PNG
- **发布中心**：各平台文案包和发布前清单。只复制，不连接平台，也不会真正发布
- **账号空间**：班级名、默认年级、常用平台、口吻备注，用作新对话的默认值
- **工具&技能**：选题钩子、一稿多发、平台文案规范等页内说明

年级：新高一 / 高一 / 高二 / 高三。功能：找选题 / 写笔记成稿 / 仿爆款大纲 / 口播脚本 / 做配图。

发布前请人工审核。换浏览器或清除站点数据后，本地草稿会消失。
