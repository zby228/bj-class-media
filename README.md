# 北京高中班级新媒体工作台

纯静态页面，放在仓库根目录，由 GitHub Pages 从 `main` 发布。打开 [https://zby228.github.io/bj-class-media/](https://zby228.github.io/bj-class-media/) 就能用，不需要登录、后端或密钥。

选题、五版文案、审核、封面和草稿都在浏览器里完成。数据记在 `localStorage` / `sessionStorage`，换浏览器或清除站点数据后会消失。

## 这条链路在做什么

班级一条素材，要发到小红书、视频号、抖音、朋友圈和私聊。这个页面把闭环留在本地：

```
链接或现成文案
    ↓  演示解析（不访问链接，只靠关键词猜平台和场景）
素材 + 年级口径（新高一 / 高一 / 高二 / 高三）
    ↓  本地模板，五个渠道各写一版
小红书图文 · 视频号 · 抖音 · 朋友圈 · 私聊话术
    ↓  本地违禁词、配图大纲
发布助手：复制标题 / 正文 / 话题，打开平台创作页
    ↓
由人在平台里粘贴，并自己点发布
```

## 怎么用

1. **素材入口**：粘贴小红书、公众号、抖音、视频号链接，点「演示解析」；或切换成「粘贴现成文案」。解析卡上会标「演示」。改完标题和正文再往下走。
2. **一稿多投**：先选年级。新高一偏适应，高一偏班刊，高二偏选择，高三偏减压、不晒分。点生成后得到五版不同文案。私聊里保留 `{昵称}` 和 `{年级}`，朋友圈不带 `#`。
3. **热点雷达**：小红书 / 抖音 / 视频号 / 公众号四栏，外加低粉样本。可以按粉丝上限和互动筛选。封面、赞、藏、评都是离线演示数，栏上有「演示数据」。
4. **违禁词**：内置词库做字符串匹配，标出风险和命中词。也可以自添词，存在本机。
5. **做配图**：五页大纲、配图提示词和一张 1080×1440 的大字封面。可以下载 PNG。不会调用出图接口。
6. **草稿箱**：保存、续编、删除。
7. **发布助手**：按渠道复制。有公开创作页的平台只是打开链接。页面没有「发布成功」。
8. **账号空间**：班级名、默认年级、常用平台、口吻。
9. **工具&技能**：十条可以复制的班级提示，不是远程安装的技能。

快捷键：在素材入口或一稿多投里按 `Ctrl/⌘ + Enter` 生成。

## 静态演示，而不是接口

下面这些能力在完整的本地自媒体工具里通常会打到外部服务。这个 Pages 站点故意不接：

| 环节 | 完整工具里常见做法 | 本站 |
|---|---|---|
| 链接解析 | 浏览器抓取正文和配图 | 看网址猜平台，填入标明「演示」的占位文案，可手改 |
| 一稿多投 | 调用大模型一次写出多版 | 本地模板，按年级改语气，并检查五版正文彼此不同 |
| 热点 / 低粉 | 第三方热榜接口 | 页面内置改编后的校园向样本，标成演示数据 |
| 违禁词 | 外部敏感词接口 | 本地词库 |
| 配图 | 付费出图 | 只给大纲、提示词和 canvas 封面 |
| 发布 | 自动把标题正文填进发布页 | 只复制，并打开创作网址；发布按钮必须人来点 |

不内置 Playwright 自动填表，不调用 DeepSeek、红狐或红鸦，也不要在文案里写成「已经发出去了」。

热点和低粉数字用来练习筛选，不代表真实账号、真实热度或学校官方校历。发出去之前请班主任或负责老师看过，并确认肖像、成绩和联系方式没有写进去。

## 文件

- `index.html`：页面
- `workbench.js`：年级口径、样本、文案模板、审核和筛选

本地预览：

```bash
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。不要用「直接双击文件」以外的方式依赖接口；推荐用上面的静态服务，和 Pages 一样。
